Astro Tweaks - add your own .bat tweaks
=====================================

ONE-TIME SETUP
1. Install Go:      https://go.dev/dl
2. Install Python:  https://www.python.org/downloads
   (tick "Add python.exe to PATH" during setup)
3. Unzip Astro Tweaks-Tweaks-source.zip.
4. Unzip this kit into that same folder. If Windows asks to replace files, say Yes.

EVERY TIME YOU WANT TO ADD OR CHANGE A .BAT
1. Put the .bat file in the "custom" folder.
2. Double-click build.bat.
3. Your new "Astro Tweaks.exe" appears in the folder.

The first build takes a few minutes while Go downloads what it needs.
After that it takes under a minute.

THE OPTIMISER .BAT ("Fortnite optimiser") - CHANGE IT ANY TIME FROM THE ADMIN PAGE
1. Open https://astrotweaks.app/admin > Live tweaks > "Optimiser .bat".
2. Type the name people see and one line about what it does.
3. Pick your .bat (or paste it) and click "Save and make live". No app update needed.
   To stop it everywhere, click "Remove it".

What people see: next time they open the app, a window asks
"Allow Fortnite optimiser to make changes and open other apps?" with every command listed.
 - Allow: the whole .bat runs now and every time the app opens (no console window; apps it starts
   show normally; "pause" can't hang it). Its output goes into the app's log.
 - Don't allow: it never runs.
Each time you save a CHANGED .bat, everyone who allowed the old one is asked again before the new one
runs. People who said no aren't nagged; they can switch it on at the bottom of Settings.
Turning it off (or "Undo all") puts back the Windows settings it changed. Apps it installed stay installed.

Keep your admin password long and private: whoever has it can change what this .bat runs.
