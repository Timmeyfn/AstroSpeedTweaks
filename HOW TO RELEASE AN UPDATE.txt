AstroSpeed - releasing an update (all on Cloudflare, no GitHub)
===============================================================

How it works:
  The app checks  https://astrospeed.dupelication.workers.dev/version.json
  If the version there is higher than the one installed, it shows
  "AstroSpeed X is ready" -> Update now -> it downloads inside the app with a
  progress bar, installs itself and restarts. People never leave the app.

To release a new version (Claude normally builds the exe for you):

  1. Upload the new exe to your download worker (astrospeedtweaks) with the
     SAME name:  AstroSpeed Tweaks.exe   (replace the old one).

  2. Open your website worker (astrospeed) > Edit code. At the top, change:
        const APP_VERSION = "1.8.0";      <- make this the new number, e.g. "1.8.1"
        const NOTES = "...";              <- what's new (each line starts with "- ",
                                             separate lines with \n)
     Deploy.

That's it. Everyone on an older version gets the in-app update next time they
open AstroSpeed. The version number in step 2 must match the new exe's version
and be HIGHER than the last one.
