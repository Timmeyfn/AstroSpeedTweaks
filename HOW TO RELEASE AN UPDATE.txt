AstroSpeed - how updates work
=============================

Your repo:  https://github.com/Timmeyfn/AstroSpeedTweaks
update-repo.txt is ALREADY set to  Timmeyfn/AstroSpeedTweaks  -  don't change it.


1) ADDING TWEAKS (most of the time - nothing to build)
------------------------------------------------------
- Go to the repo > open the "tweaks" folder > Add file > Upload files
- Drop your .bat in > Commit changes
Done. Everyone's AstroSpeed gets it by itself within ~30 minutes
(or straight away: Settings > Online pack > Check now).
No release, no new exe, no version number.


2) RELEASING A NEW VERSION OF THE APP (only when the app itself changes)
-----------------------------------------------------------------------
Usually Claude does steps 1-2 for you and gives you the zip.

1. Open main.go and raise the version number, e.g.
       const AppVersion = "1.5.0"   ->   const AppVersion = "1.5.1"
2. Run build.bat, then zip "AstroSpeed Tweaks.exe"
   (right-click > Send to > Compressed (zipped) folder).
3. Go to https://github.com/Timmeyfn/AstroSpeedTweaks/releases/new
   - Choose a tag: type  v1.5.1  (same number, with a v) > "Create new tag"
   - Release title: AstroSpeed 1.5.1
   - Description: what changed. Lines starting with "- " show as a list.
   - Drag the zip into the box at the bottom
   - Click "Publish release"

Next time anyone opens an older AstroSpeed, it says a new version is ready,
shows your notes and has a Download button.
