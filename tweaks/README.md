# Drop your .bat files here

Every `.bat` file in this folder shows up in AstroSpeed as its own switch in the **Online tweaks** section.
No rebuilding needed: everyone's app picks it up within about 30 minutes, or straight away with
Settings > Online pack > Check now.

1. Open this folder on github.com
2. Add file > Upload files > drop your .bat in > Commit changes

To remove one, open the file on github.com, click the ... menu > Delete file, then commit.
