Hosting the download for free (Cloudflare Pages — no card needed)
================================================================

R2 asks for a card. Cloudflare PAGES does not, and it hosts files free.
You'll put the .exe on Pages, then paste its link into the website.

1. Get the .exe:
   - Unzip AstroSpeed-Tweaks-v1.7.0.zip. Inside is "AstroSpeed Tweaks.exe".
   - Rename it to  AstroSpeed.exe  (no spaces = a tidy link). It still runs the same.

2. Put it on Cloudflare Pages:
   - Cloudflare dashboard > Workers & Pages > Create.
   - Click the "Pages" tab > "Upload assets" (direct upload, NOT the Git option).
   - Project name:  astrospeed-download   > Create project.
   - Drag  AstroSpeed.exe  into the upload box > Deploy site.

3. Get the link:
   - After it deploys, your file is at:
        https://astrospeed-download.pages.dev/AstroSpeed.exe
     (If Cloudflare gave the project a slightly different name, use that name.)
   - Open that link in a browser to check it downloads the .exe.

4. Put the link in the website:
   - Open your website worker (astrospeed...workers.dev) > Edit code.
   - Near the very bottom, find this line:
        var DOWNLOAD_LINK = "";
   - Put your link between the quotes:
        var DOWNLOAD_LINK = "https://astrospeed-download.pages.dev/AstroSpeed.exe";
   - Deploy.

Done — the "Download for Windows" button now downloads your .exe, all on Cloudflare,
nothing from GitHub.

New version later: go to the Pages project > Create new deployment > upload the new
AstroSpeed.exe (same name). The button serves the new file.
