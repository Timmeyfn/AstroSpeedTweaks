Hosting the download on your own Cloudflare (no GitHub)
=======================================================

The website's "Download for Windows" button points at /download on your own site.
You serve the .exe from Cloudflare R2 storage (free up to 10 GB). One-time setup:

1. Get the .exe file:
   - Unzip AstroSpeed-Tweaks-v1.7.0.zip. Inside is "AstroSpeed Tweaks.exe".
     (Keep the name exactly as it is.)

2. Make an R2 bucket:
   - Cloudflare dashboard > R2 > "Create bucket". Name it e.g.  astrospeed-files  > Create.
   - (R2 is free to turn on; it may ask you to add a card but the free tier covers this easily.)

3. Upload the file:
   - Open the bucket > "Upload" > choose "AstroSpeed Tweaks.exe".

4. Connect the bucket to your WEBSITE worker (astrospeed...workers.dev):
   - Open that Worker > Settings > Bindings > Add > "R2 bucket".
     Variable name:  FILES      Bucket:  astrospeed-files     > Deploy.

5. Make sure the website Worker is running website-worker.js, then Deploy.

Test: open  https://astrospeed.dupelication.workers.dev/download  — it should download
the .exe. The "Download for Windows" button now does the same.

To ship a new version later: upload the new .exe to the bucket with the SAME name
(AstroSpeed Tweaks.exe), replacing the old one. The button serves the new file.
