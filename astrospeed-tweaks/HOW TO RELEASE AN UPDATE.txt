AstroSpeed - releasing an update
================================

ONE-TIME SETUP
1. Make a free account at github.com (if you don't have one).
2. Click "+" (top right) > "New repository". Name it, e.g. astrospeed-tweaks.
   Set it to Public, then click "Create repository".
3. Open update-repo.txt in this folder and add one line with
   your-github-name/astrospeed-tweaks
4. Run build.bat and share the new "AstroSpeed Tweaks.exe".
   Copies built before this step can't check for updates, so make sure
   everyone gets a copy built after it.

EVERY TIME YOU RELEASE A NEW VERSION
1. Open main.go in Notepad and change the version number, e.g.
       const AppVersion = "1.4.0"   ->   const AppVersion = "1.5.0"
   (The number must be higher than the last one.)
2. Run build.bat.
3. Zip "AstroSpeed Tweaks.exe" (right-click > Send to > Compressed folder).
4. On your GitHub repository page click "Releases" > "Draft a new release".
   - Tag: v1.5.0   (the same number with a v in front)
   - Title: anything, e.g. "AstroSpeed 1.5.0"
   - Description: what changed. Lines starting with "- " show as a list.
   - Drag the zip into the box at the bottom.
   - Click "Publish release".

Next time anyone opens an older AstroSpeed, it shows
"AstroSpeed 1.5.0 is ready" with your notes and a Download update button.
