AstroSpeed Tweaks - adding things from GitHub (no rebuilding needed)
=====================================================================

Once update-repo.txt has your repository in it and you've built the exe once,
every copy of AstroSpeed reads two things from that same GitHub repository:

    astrospeed.json      tweaks, sections, new games, game pictures, a message
    tweaks\*.bat         every .bat file in a folder called "tweaks" becomes a switch

It checks when AstroSpeed opens and every 30 minutes. To check straight away:
Settings > Online pack > Check now. GitHub can take up to 5 minutes to show a change.

Nothing from the pack runs by itself. People still switch it on or press Optimize,
and Undo works the same as for every built-in tweak.


FIRST TIME SETUP (2 minutes)
----------------------------
1. Open your repository on github.com (the same one you put in update-repo.txt).
2. Click "Add file" > "Upload files".
3. Drag in astrospeed.json and the tweaks folder from this "github-repo-starter" folder.
4. Click "Commit changes".
5. Open AstroSpeed > Settings > Online pack > Check now. You'll see the counts go up
   and an "Online tweaks" / "Extras" section appear in the menu.

The repository must be public, or AstroSpeed can't read it.


THE EASY WAY: .BAT FILES
------------------------
1. In your repository, open the "tweaks" folder.
2. "Add file" > "Upload files", drop your .bat in, "Commit changes".

Each .bat becomes one switch in the "Online tweaks" section, named after the file
(my_fps_tweaks.bat shows as "My fps tweaks"). The first "rem" line becomes its description.

Same rules as build.bat:
  - reg add / reg delete, sc config ... start=, schtasks /change /disable and
    bcdedit /set lines are backed up and undone exactly.
  - Other commands (netsh, powercfg, ...) run as they are. Undo can't reverse those.
  - echo, pause, cls, title, menus, goto, set, if/for blocks are skipped.
    Settings > Online pack lists every skipped line so you can see what happened.

To remove a .bat tweak, delete the file on GitHub. People who had it on can still
press "Undo all" to put back what it changed.


THE FULL WAY: astrospeed.json
-----------------------------
Edit astrospeed.json on GitHub (click it, then the pencil icon). Lines starting with
// are notes and are ignored. The starter file has a working example of everything.

"message"     One line shown at the top of the app until each person dismisses it.
              Change it to show a new message. Use "" for none.

"categories"  New sections in the side menu: id, title, nav (short menu name),
              subtitle, icon (spark, gamepad, cpu, wifi, bolt, chip, gpu, eye, layers).

"tweaks"      Each tweak needs:
                id        unique, lowercase, e.g. "my-ecn-off"
                cat       a section id: your own, or a built-in one such as
                          "gaming", "cpu", "power", "network", "gpu", "apps",
                          "background" (Privacy), "services", "kernel" (BIOS)
                title, desc, benefit   text shown in the app
                impact    1, 2 or 3
                risk      "safe", "moderate" or "expert" (expert is never in Optimize)
                profile   1 = Recommended, 2 = Competitive, 0 = only by hand
                actions   the changes, any of:
                  { "kind":"reg", "root":"HKLM", "path":"SOFTWARE\\...", "name":"Value", "type":"DWORD", "num":1 }
                  { "kind":"reg", ... "type":"SZ", "str":"text" }
                  { "kind":"regdel", "root":"HKCU", "path":"...", "name":"Value" }
                  { "kind":"svc", "svc":"ServiceName", "start":"disabled" }   (or manual / auto)
                  { "kind":"task", "task":"\\Microsoft\\Windows\\...\\TaskName" }
                  { "kind":"bcd", "key":"disabledynamictick", "val":"yes" }
                  { "kind":"cmd", "apply":"netsh ...", "revert":"netsh ..." }
                  { "kind":"ps",  "apply":"PowerShell command", "revert":"..." }
              Registry paths use \\ (two backslashes) inside JSON.

"games"       Add a game with its own page and the 5 standard game tweaks:
                id, name, studio, exes (["Game.exe"]), color ("#RRGGBB"),
                steamDir (folder under steamapps\common), epicApp, riot,
                apps (name in Windows "Installed apps"), paths (folders to look in,
                ?: = any drive), rel (where the exe sits inside the game folder),
                image (an https:// picture link, 460x215 or wider looks best)

"images"      Swap the picture of any game, built-in ones too:
                "images": { "rust": "https://.../rust.jpg", "sot": "https://..." }
              Tip: upload a picture to your repo, open it, click "Raw" and copy that link.


SAFETY CHECKS (built into the app, you can't turn them off)
-----------------------------------------------------------
Anything that breaks these rules is left out and listed in Settings > Online pack:
  - Nothing that touches mouse/keyboard sensitivity, Fortnite or game settings files,
    Windows Defender, Windows Update, the firewall or UAC.
  - Registry changes only in HKLM or HKCU.
  - No commands that wipe disks or files, change accounts or permissions, shut down
    the PC, edit boot entries directly, or download and run files from the internet.
  - Ids that clash with built-in tweaks are refused.
If astrospeed.json has a typo, the app says where, and keeps using the last good copy.


KEEP YOUR GITHUB ACCOUNT SAFE
-----------------------------
Whatever you put in this repository runs with administrator rights on the PC of
everyone who uses AstroSpeed and switches it on. Turn on two-factor authentication
(github.com > Settings > Password and authentication) and don't give others write access.
